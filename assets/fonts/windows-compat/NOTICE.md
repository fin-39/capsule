# Windows compatibility font pack

Capsule redistributes these open-source compatibility fonts from the font pack
shipped with Valve Proton Experimental. They provide Windows-compatible family
names without containing Microsoft proprietary font data.

The files are exposed read-only to contained Wine applications. They remain
separate font software under their original licenses and are not relicensed as
part of Capsule.

## Liberation Fonts derivatives

Files: `arial.ttf`, `arialbd.ttf`, `cour.ttf`, `courbd.ttf`, `georgia.ttf`,
`times.ttf`

Hat, Inc. Licensed under the SIL Open Font License 1.1 in
`LICENSE.OFL.txt`. The reserved upstream font names are not used as the primary
names of these compatibility builds.

The binary files were collected from Proton Experimental's
`files/share/fonts` directory on 2026-07-21. Proton's accompanying license
notice identifies the upstream projects as Liberation Fonts, Source Han Sans,
Ume fonts, and Google Noto.
